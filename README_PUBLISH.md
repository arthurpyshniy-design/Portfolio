# Обновление Portfolio: кейс циферблата Xiaomi Watch S5

В архиве подготовлены файлы для добавления кейса в репозиторий `arthurpyshniy-design/Portfolio`:

- `index.html` — обновлённая главная страница с карточкой и ссылкой на кейс;
- `xiaomi-watch-s5.html` — русскоязычная страница кейса;
- `assets/watchface/` — восемь отобранных и оптимизированных кадров процесса.

## Какие кадры выбраны

1. Первый фрейм 480 × 480 в Figma.
2. Круглая направляющая для проверки обрезки.
3. Эксперимент с размещением системного времени.
4. Игровой референс на отдельной странице Figma.
5. Базовая форма бумажной метки в Krita.
6. Неудачная текстура с ореолом и тёмным артефактом.
7. Проверка типографики `R.C.M. / FILE № 4217-A`.
8. Финальная композиция в Figma.

Из полного архива выбраны только кадры, показывающие разные решения. Все 160 изображений в публичный сайт не переносятся.

## Как опубликовать

1. Распакуй этот архив на компьютере.
2. Открой или клонируй репозиторий `https://github.com/arthurpyshniy-design/Portfolio.git` в VS Code.
3. Скопируй `index.html`, `xiaomi-watch-s5.html` и папку `assets` в корень репозитория, заменив `index.html`.
4. В разделе Source Control проверь изменения, создай коммит `Add Xiaomi Watch S5 watchface case study` и отправь его в `main`.
5. После успешной сборки GitHub Pages проверь адрес `https://arthurpyshniy-design.github.io/Portfolio/xiaomi-watch-s5.html`.

## Ограничения, отражённые в кейсе

- Макет 480 × 480 px предназначен для круглого дисплея.
- Доступны только динамические поля, поддерживаемые платформой циферблата.
- Изображение в кейсе — кадр Figma, не фотография циферблата на реальных часах. В предоставленном архиве отдельное фото экрана не найдено.
- Проект — неофициальный фанатский концепт. Используемая иллюстрация Disco Elysium принадлежит соответствующим правообладателям. Для коммерческого использования графику нужно заменить на собственную или лицензированную; указание правообладателя само по себе не даёт разрешения.
- В кейсе прозрачно описано использование ИИ для консультаций; композиционные решения и редактирование макета выполнялись под управлением автора.
