01 / Context

Задача

Собрать проекты в одном месте, хотя они отличаются по тематике и готовности. Часть материалов уже существует в GitHub, часть пока хранится на компьютере, а некоторые проекты не следует публиковать целиком.

Сайт должен показывать направление работы и статус проекта, не требуя переносить все исходники в один репозиторий.

02 / Constraints

Ограничения

  • Использовать бесплатный способ публикации и не покупать домен на первом этапе.
  • Сохранить исходники каждого проекта отдельно; не превращать сайт в общий монорепозиторий.
  • Не раскрывать приватный код, командные материалы и личные данные без проверки разрешений.
  • Сделать первую версию простой в поддержке, без сервера, базы данных и обязательной сборки.
03 / Approach

Подход и реализация

Статическая страница

Главная страница реализована в одном файле index.html; стили CSS находятся внутри файла. JavaScript и серверная часть в текущей версии не используются.

Карточки со статусами

Каталог показывает четыре проекта: GlyphDeck, FiberWatch, циферблат Xiaomi Watch S5 и Кабанан / NRI. Указывается, если материалы пока локальные или исходники приватные.

Простая адаптивная сетка

В CSS есть контрольная точка на ширине 640 px: карточки переключаются с двух колонок на одну. Фактическая проверка на телефоне ещё не проводилась.

Публикация из репозитория

Исходник и README размещены в публичном репозитории Portfolio; опубликованная страница доступна по адресу GitHub Pages.

04 / Verification

Что проверено

  • Страница открывалась в браузере; визуальная проверка по скриншоту подтвердила отображение шапки, вводного блока, каталога, информации о портфолио и подвала.
  • В репозитории проверены index.html, README.md и отдельная страница этого кейса portfolio-case.html.
  • В исходнике присутствуют метатег viewport и CSS-правило для узкого экрана.

Граница проверки: не проводились автоматические тесты, проверка доступности для скринридеров, замеры производительности или полноценная проверка на мобильном устройстве. Никакие количественные показатели качества не заявляются.

05 / Contribution

Роль автора и использование ИИ

Автор определил назначение сайта, состав направлений, требования к приватности, создал репозиторий и проверил опубликованную страницу в браузере. Первичная HTML/CSS-реализация и текст README были подготовлены с помощью ChatGPT и внесены в репозиторий с использованием GitHub-инструментов.

Поэтому эту версию корректно описывать как AI-assisted prototype, а не как полностью самостоятельно написанный код.

06 / Outcome & next steps

Результат и дальнейшая работа

Создан и опубликован работающий каталог с четырьмя карточками проектов. Он даёт общую точку входа, сохраняя отдельное хранение исходников и позволяя обозначать ограничения публикации.

  • Добавить отдельные кейсы с доказательствами результата и ссылками на доступные материалы.
  • Проверить вёрстку на реальном телефоне и на обычном масштабе браузера.
  • Добавить прямые ссылки только там, где материалы действительно доступны и согласованы к публикации.
  • Обновлять описания и статусы по мере развития проектов.
Current limitations

Ограничения текущей версии

Каталог пока содержит краткие описания, но не все карточки ведут на самостоятельные страницы проектов. Нет CMS, фильтрации, поиска по категориям или автоматического обновления каталога. Это сознательно оставлено за пределами первой версии.
